# OpenBeekeeper 🐝

Помощник пчеловода для OpenComputers, Forestry и Gendustry на McSkill HiTech 1.12.2.

Цель проекта — собрать коллекцию видов пчёл: учитывать линии, размножать родителей,
скрещивать их в обычном мутатроне и сохранять результаты.

**Текущий статус: диагностический сканер. Автоматическое разведение ещё не реализовано.**
Взаимодействие с устройствами вручную проверено в игре; сам сканер ещё нужно проверить там.

## Проверенная установка

- OpenOS 1.8.10, компьютер с интернет-картой.
- Транспозер OpenComputers, адрес на момент настройки: `56400f67-5415-4a3e-b5a0-65b621757596`.
- Сторона `2` (север): промышленная пасека, 15 слотов.
- Сторона `3` (юг): сундук пчеловода, 125 слотов.
- Сторона `4` (запад): обычный мутатрон Gendustry.
- Устройства касаются граней транспозера. Кабель соединяет транспозер с компьютером.
- На этом сервере для доступа понадобилось добавить `OpenComputers` в регион.

Номера сторон относятся к миру, а не к направлению взгляда игрока.

## Запуск

Скопируйте `openbeekeeper.lua` на игровой компьютер и запустите из OpenOS:

```sh
lua openbeekeeper.lua
```

Программа только читает инвентари: показывает стороны, слоты, предметы и доступный
идентификатор вида пчелы. Предметы не переносит и не уничтожает. Если транспозеров
несколько, укажите нужный адрес или его уникальное начало:

```sh
lua openbeekeeper.lua 56400f67
```

После публикации репозитория диагностический файл можно будет скачивать через
интернет-карту командой `wget` по его настоящей raw-ссылке. Учётные данные GitHub
в игровой компьютер передавать не нужно.

## Слоты устройств

| Устройство | Слоты | Назначение |
|---|---|---|
| Обычный мутатрон | 1 | Принцесса |
| Обычный мутатрон | 2 | Трутень |
| Обычный мутатрон | 3 | Матка, результат |
| Обычный мутатрон | 4 | Genetics Labware |
| Промышленная пасека | 1 | Принцесса или матка |
| Промышленная пасека | 2 | Трутень |
| Промышленная пасека | 3–6 | Улучшения — не извлекать при сборе |
| Промышленная пасека | 7–15 | Выход, диапазон требует дальнейшей проверки |

В наблюдавшемся цикле потомство находилось в слотах 8 и 9, соты — в 7.
Программа разведения должна определять тип предмета, а не рассчитывать на постоянный
номер выходного слота.

## Что подтверждено в игре

- Чтение инвентарей транспозером после настройки региона.
- Перенос принцессы в слот 1 пасеки и трутня в слот 2.
- Обычный мутатрон сам запускает процесс при наличии подходящей пары и ресурсов.
- Cultivated Princess + Common Drone дали Diligent Queen.
- Перенос этой матки из слота 3 мутатрона в слот 1 пасеки.
- После её цикла получены Diligent Princess и два Diligent Drone.
- Через адаптер у пчелы читался `individual.ident`. У непроанализированных пчёл
  полные активные и неактивные гены в показанном выводе отсутствовали.

У доступного через адаптер продвинутого мутатрона не обнаружена команда выбора
мутации: доступны методы энергии и инвентаря. Поэтому проект ориентируется на
обычный мутатрон, с проверкой фактического результата каждого скрещивания.

## Следующие этапы

1. Проверить диагностический файл в игре, в том числе `individual` через транспозер.
2. Сохранять каталог видов по стабильным ID, отдельно учитывать принцесс, маток и трутней.
3. Сделать возобновляемый цикл пасеки с ожиданием реального завершения, проверкой
   перенесённого количества и остановкой при заполнении сундука.
4. Управлять обычным мутатро­ном, сохраняя исходные линии до расходования принцессы.
5. Добавить проверенную для сервера базу скрещиваний, ограничения и планировщик.

Наличие хотя бы одного вида ещё не означает сохранённую линию. Для продолжения
нужны воспроизводимые родители и запас трутней. Мутатрон расходует принцессу;
использовать последнюю принцессу исходной линии без стратегии восстановления нельзя.
Полный список доступных на сервере видов и рецептов пока не собран.
