# Клиентский справочник пчёл

`src/bee-catalog.json` — извлечённый справочник установленной клиентской сборки
McSkill HiTech 1.12.2. В нём 176 видов: 44 Forestry, 116 Extra Bees и 16
цветных Gendustry. Для вида сохранены нативные гены, требования среды, эффект,
продукция с вероятностями и известные клиенту рецепты мутаций.

Источники фиксируются в поле `sources`: точные JAR клиента, встроенные конфиги
Gendustry и локализации. `tools/extract_bee_catalog.py` повторяет извлечение из
Java, декомпилированного CFR 0.152. Пример:

```sh
python3 tools/extract_bee_catalog.py \
  --decompiled /tmp/openbeekeeper-decompiled \
  --client /path/to/Hitech1122jvm21
```

Это клиентский, а не серверный каталог. Сервер может переопределять рецепты,
условия, эффекты и вероятности. Серверные мутации следует сверять через каталог
Forestry в OpenComputers (`listAllSpecies`, `getBeeBreedingData`) и не заменять
ими клиентские данные без явной отметки происхождения.

`src/climate-data.json` остаётся компактным встроенным справочником, который
использует игровой исполнитель. Полный каталог пока не встраивается в
`openbeekeeper.lua`, чтобы не увеличивать расход памяти OpenComputers.
